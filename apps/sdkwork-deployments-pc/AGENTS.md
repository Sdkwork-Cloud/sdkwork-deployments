# SDKWork Deployments PC

Read `../../../sdkwork-specs/SOUL.md` first. This browser root follows the canonical PC, React, SDK, Drive, IAM, configuration, security, pagination, naming, frontend, TypeScript, and test standards.

Console packages consume Deploy App SDK and Drive App SDK only through console-core. Admin packages consume Deploy Backend SDK only through admin-core. Upload bytes are owned by Drive; Deploy stores stable business references. Raw HTTP, manual authorization headers, local SDK forks, generated output edits, and cross-surface business imports are forbidden.
