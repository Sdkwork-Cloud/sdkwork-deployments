# Crates

Rust crates for SDKWork Deploy:

- `sdkwork-api-deployments-standalone-gateway`: runnable HTTP API server binary
- `sdkwork-routes-deploy-*`: web-framework route adapters
- `sdkwork-intelligence-deploy-*`: service and repository layers
- `sdkwork-deploy-database-host`: database lifecycle host
- `sdkwork-deploy-runtime-compiler`: deterministic Website descriptor and node runtime-set compiler
- `sdkwork-deploy-web-port`: generated Web Internal SDK runtime assignment publisher
